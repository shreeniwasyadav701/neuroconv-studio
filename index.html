            Deep Dive: How Convolutional Neural Networks Work
          

          
A comprehensive guide to modern computer vision foundations, mathematics, and architectural intuition.

        


        


          
          

            
1

            
Local Receptive Fields & Weight Sharing

            

              Unlike traditional Fully-Connected networks where every input pixel connects to every neuron (causing parameter explosion), CNNs apply small shared filter kernels ($3 \times 3$ or $5 \times 5$).
              This exploits spatial locality: pixels close together are strongly correlated.
            

          


          
          

            
2

            
Feature Hierarchies

            

              Early convolutional layers detect elementary features like lines, edges, and color gradients.
              Intermediate layers combine these into textures and contours.
              Deep layers capture high-level semantic concepts like digit loops, dog noses, or wheel rims.
            

          


          
          

            
3

            
Translation Invariance via Pooling

            

              Max Pooling partitions feature maps into small windows (e.g. $2 \times 2$) and computes the maximum value.
              This reduces the spatial resolution, saves memory/compute, and ensures the network recognizes features even if shifted or tilted.
            

          


        


        
        

          
Essential Mathematical Formulations

          

            
            

              
Output Dimension Formula:

              
W_out = floor((W_in - K + 2P) / S) + 1

              
Where W: width, K: kernel size, P: padding, S: stride

            


            

              
Conv Layer Parameters Count:

              
Params = (K_w × K_h × C_in + 1) × C_out

              
Accounts for filter weights plus 1 bias per filter channel
